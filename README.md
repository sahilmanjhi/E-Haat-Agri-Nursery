# ITMU E-Haat - Agri Nursery

An online agricultural and plant nursery platform for ITM University E-Haat, featuring botanical catalog management, role-based admin controls, order tracking, and live cart checkout.

## Overview
- **Storefront**: Browse indoor plants, flowering varieties, fruit plants, and medicinal herbs.
- **Admin Dashboard**: Comprehensive catalog, inventory, categories, customer, and order management.
- **Cart & Orders**: Real-time cart calculations and order lifecycle tracking.

## Getting Started

### Frontend Setup
```bash
npm install
npm run dev
```

### Backend Setup
```bash
cd backend
python manage.py migrate
python manage.py runserver
```
